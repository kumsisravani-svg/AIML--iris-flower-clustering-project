# AIML--iris-flower-clustering-project
## Overview
This project uses K-Means Clustering to group Iris flowers into clusters.

## Tasks Completed
- Loaded Iris dataset
- Selected flower measurement features
- Applied K-Means clustering (k=3)
- Visualized clusters using scatter plot
- Compared predicted clusters with actual species labels

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
